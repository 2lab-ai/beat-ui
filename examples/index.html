@2lab.ai/beat-ui

Beat-synced live-code visuals as zero-dependency TypeScript patterns.

reefA beat writes its own Strudel code while three ASCII sharks circle a float and hunt on the drop. Space · D · Z. minimalA two-section beat, its code typing itself, and the beat grid — 70 lines.

The patterns

  1. One clock for sound and picture (BeatClock)
  2. The score is the single source of truth (arrange, patterns)
  3. Code text with token ranges (LineBuilder)
  4. A typewriter that edits like a person (Typewriter, CodeView)
  5. The beat grid (beatGridHtml)
  6. The pitch roll (PitchRoll)
  7. A canvas drawn in cells (cellGrid, paintWater, causticNet)
  8. A spine creature (makeSpine, moveSpine, rasterSpine)
  9. A bait ball (swimSwarm)
  10. The drop and a hunt that answers it (DropState, steerHunter)
  11. A drum machine in plain WebAudio (Synth)
  12. Receipts: the page says what it shows, in numbers (exposeReceipts)
